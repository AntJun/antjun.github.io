## Requesting a Link Exchange

<b>Requirements</b>
<br/> 1. The site is accessible and continues to receive updates.
<br/> 2. Its pages are tidy and do not contain excessive advertising.
{:.warning}

<b>Application format</b>
<br/> To exchange links, contact me or leave a comment at the bottom of this page using the following format.
<br/> 1. Website name: (e.g. @ Otonokizaka Coffee House)
<br/> 2. Website URL: (e.g. [https://www.antjun.com/](https://www.antjun.com/))
<br/> 3. Website description: (e.g. Welcome to Akira_Ant's Blog)
<br/> 4. Website avatar: (e.g. [https://www.antjun.com/favicon-32x32.png](https://www.antjun.com/favicon-32x32.png))
{:.success}
