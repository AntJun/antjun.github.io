欢迎使用 Valine 评论系统[^valine]！
<br/> 本站采用 Valine 评论系统，一款基于 [LeanCloud](https://leancloud.cn/) 的快速、简洁且高效的无后端评论系统。
<!--more-->

<span style="color:red;">**注意：评论所有权归属于 [Valine](https://valine.js.org/)**</span>
{:.warning}

## 如何使用评论

使用此评论系统不需要科学上网 XD
<br/> 每篇 Post 的底部都有评论输入框，如要对文章进行评论，直接输入评论信息发送即可。

**输入个人的昵称及电子邮箱以方便他人认出您！**
<br/> 在输入了电子邮箱的前提下，任何与此 Email 有关的回复系统都会在第一时间发送到电子邮箱。
<br/> 未输入昵称时发送的消息将以 `Anonymous` 的代名发送消息。

## 支持 Markdown

本评论系统支持 Markdown，您可以使用 Markdown 语法输入您想发表的评论。同时，您可以点击「预览」按钮来查看实时效果。
<br/> 具体请参考 [Markdown详细语法教程](https://segmentfault.com/markdown)。

## 配置个人头像 [^avatar]

Valine 目前使用的是 [Gravatar](http://cn.gravatar.com/) 作为评论列表头像。

请自行登录或注册 [Gravatar](http://cn.gravatar.com/)，然后修改自己的头像。

评论的时候，留下在 [Gravatar](http://cn.gravatar.com/) 注册时所使用的邮箱即可。

> 感谢 `gravatar.cat.net` 提供的补充服务。

<span style="color:red;">**注意：因 gravatar.cat.net 有七天的缓存期，修改头像后请耐心等待更新**</span>
{:.warning}

## 处理垃圾评论

本评论使用 [Akismet](https://akismet.com/) 处理垃圾评论。
点击[此处](https://akismet.com/privacy/)了解详情。
